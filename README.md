Turning Project Data into Powerful Insights! 🚀


---

🌟 About the Project

Welcome to Project Pulse, an interactive Excel dashboard designed to simplify project tracking, monitor task completion, and visualize project performance.

This project transforms raw project management data into meaningful insights using Microsoft Excel's powerful data analysis and visualization features.

With an organized dashboard, users can quickly understand project progress, identify pending tasks, and monitor task assignments.

The goal is simple: Track Better. Analyze Smarter. Manage Projects Efficiently.


---

🎯 Project Objectives

The main objectives of this project are to:

📌 Organize and clean project management data.

📈 Analyze tasks across different projects.

👥 Track employee task assignments.

✅ Monitor task completion percentages.

📊 Visualize project performance through interactive charts.

🎛️ Enable dynamic filtering using slicers.

💡 Support better project monitoring and decision-making.



---

🗂️ Dataset Overview

The dashboard uses a Project Management Dataset containing the following fields:

Column	Description

Project Name	Name of the project
Task Name	Individual task associated with a project
Assigned To	Employee responsible for the task
Start Date	Date when the task begins
Days Required	Estimated duration of the task
End Date	Expected or recorded task completion date
Progress	Percentage of task completion
Task Status	Completion status calculated using Excel formulas


The dataset allows users to analyze task distribution, monitor progress, and compare projects.

---

📊 Dashboard Highlights

1. 📌 KPI Cards

Quickly view important project statistics:

Total Tasks: Number of tasks recorded.

Completed Tasks: Tasks that have reached 100% progress.

In Progress: Tasks that have started but are not yet complete.

Not Started: Tasks with 0% progress.


2. 📈 Project Analysis

Compare the number of tasks across different projects to understand how work is distributed.

3. 🎯 Progress Monitoring

Visualize average task progress across projects to identify which projects are progressing well and which may require attention.

4. 🍩 Task Completion Analysis

Understand the distribution of completed, ongoing, and pending tasks through a doughnut chart.

5. 🎛️ Interactive Filtering

Use slicers to filter project information and explore the data dynamically.

Note: Dashboard components respond to slicers only when the relevant PivotTables and charts are correctly connected.

---

🚀 How to Use the Dashboard

Step 1: Open the Excel workbook.

Step 2: Navigate to the Dashboard worksheet.

Step 3: Review the KPI cards to understand overall task status.

Step 4: Explore the charts to compare project performance.

Step 5: Use the Project Name and Task Status slicers to filter the information.

Step 6: Review the updated results to understand the selected project's performance.

Step 7: Return to the full dataset whenever you need to inspect individual tasks.
